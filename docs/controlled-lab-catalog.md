# 受控检验项目目录

> 状态：待人工审核候选目录（`reviewState = human_review_required`）。目录中的名称、提示、国家标准数据元引用和 LOINC 代码均只在代码已有证据范围内表达，不构成医学最终审核或正式映射。

## 1. 目录用途与数量

`src/data/controlledLabCatalog.ts` 是应用内用于推荐标准标签的本地受控候选目录，当前共 **32 条**。其中 **31 条**属于 `CATALOG_RECOMMENDABLE`，另有 1 条因 `evidenceStatus = withheld` 暂缓，不参与代理提示、确定性匹配或模型推荐。本批已核验提升为 `verified_candidate` 的项目为：ALT（1742-6）、AST（1920-8）、GGT（2324-2）、ALP（6768-6）、总胆红素（Bilirubin.total，1975-2）、白蛋白（1751-7）、尿酸（3084-1）；这些条目现有标本均为血清，方法字段保持未指定。总胆红素不包含直接胆红素，直接胆红素仍为 `withheld`（1968-7）。

后续小批次核验提升 4 项为 `verified_candidate`：中性粒细胞百分比（lab-neut-pct）、淋巴细胞百分比（lab-lymph-pct）、空腹血糖（lab-fpg，已明确为**空腹**语义，见 `nationalStandard` 空腹血糖值）、促甲状腺激素（lab-tsh）。其中空腹血糖仅保留**空腹**语义别名（FPG/显示名 空腹血糖）参与自动命中；普通血糖语义（血糖/GLU/葡萄糖/普通血糖）**绝不并入空腹血糖**，也不作为独立目录条目。

后续小批次核验提升 3 项为 `verified_candidate`：高密度脂蛋白胆固醇（lab-hdl）、低密度脂蛋白胆固醇（lab-ldl）、总蛋白（lab-tp）。这三项显示名/别名/标本与医学名称明确一致且无语义歧义：高密度与低密度脂蛋白胆固醇**各自独立条目、绝不混成单一项目**；总蛋白与白蛋白（lab-alb）**绝不混同**。三者标本分别为血清/血浆、血清/血浆、血清，方法字段保持未指定；未取得逐项国家标准数据元与 LOINC 候选的仍不填写（`nationalStandard`/`loincCodeCandidates` 保持为空，不推断）。

最后小批次核验提升 3 项为 `verified_candidate`：游离三碘甲状腺原氨酸（lab-ft3）、游离甲状腺素（lab-ft4）、甲状腺过氧化物酶抗体（lab-tpoab）。这三项显示名/别名/标本（血清）与医学名称明确一致且无语义歧义：FT3/FT4/TPOAb **各自独立条目、绝不混成单一项目**，也不与促甲状腺激素（lab-tsh）混同。三者 `nationalStandard`/`loincCodeCandidates`/`nationalCode` 保持为空（未逐项核验，不推断）；方法字段保持未指定。至此目录内 `pending_review` 条目清零。

目录只用于推荐。识别出的项目名经规范化后与目录显示名/别名精确命中，或命中用户已确认的别名映射时，给出推荐；无确定性命中时，识别服务只能从发送的可推荐目录 ID 中推荐。推荐必须由用户显式采用后才写入 `standardLabel`，且条目仍为待确认（`confirmed = false`）。

`lab-urea` 对应的是 **血尿素氮**（LOINC 3094-0 / 国家数据元血尿素氮检测值），不是普通“尿素”。当前只保留与证据一致的别名与边界：可识别 `BUN`、`血尿素氮`，但不把“尿素”自动并入该条目；该条目仍处于当前目录的候选/审核状态，不因语义相近而自动合并到“尿素”。

后续核验批次（钠 2951-2、钾 2823-3、氯 2075-0、总钙 17861-6、普通 CRP 1988-5、ESR 30341-2）在现有目录中均**无对应条目**，故本批**未新增任何条目**，证据状态计数不变。该批证据仅用于边界说明，不据此把总钙等同离子钙、普通 CRP 等同 hs-CRP，也不推断 ESR 为 Westergren/Wintrobe 等方法；`method` 未知保持 `null`。

规范化（去首尾空白、折叠空白、大小写处理及必要的展示清理）仅用于匹配定位，不修改展示或存储的原文；不会把相似的 `Al`、`A1`、`AI` 或 `HbAlc` 猜测纠正为其他项目。

条目内 `source`、`sourceUrl`、`sourceVersion` 是逐项证据范围内的来源记录。代码中没有把国家卫健委首页作为条目来源 URL；已核验标准引用使用上述官方 PDF URL。未逐项取得国家标准数据元依据的条目保持 `nationalStandard = null`、`nationalCode = null`，不扩大结论。

## 3. 证据状态与规则

`evidenceStatus` 描述证据处理状态，不等于医学签核：

| 状态 | 含义 | 推荐规则 |
| --- | --- | --- |
| `verified_candidate` | 已核验为候选证据，达到目录确定性匹配的证据门槛 | 可参与精确目录匹配；推荐仍须用户采用和确认 |
| `pending_review` | 待逐项复核的候选 | 不参与自动目录精确匹配；可作为模型候选，须用户采用 |
| `withheld` | 因语义边界或其他已记录问题暂缓 | 不参与目录简表、确定性匹配、用户别名推荐或模型推荐 |

当前状态计数：`verified_candidate` 31 条，`pending_review` 0 条，`withheld` 1 条。待复核剩余清单：无（`pending_review` 条目已清零）。

`reviewState` 仍统一为 `human_review_required`。`nationalCode` 当前全部为 `null`，不代表国家代码已核验或缺省代码可推断。

## 4. LOINC 候选与许可

代码中的 `loincCodeCandidates` 仅记录现有已核验范围内的候选代码、官方条目 URL、协议和使用条件。候选代码不是最终映射；不得仅凭中文项目名、代码或单位推断标本、方法、协议或可互换关系。已有代码中的边界条件必须保留，目录不据此扩大医学结论。

使用 LOINC 字段时保留 `LOINC_LICENSE_NOTICE`。许可声明采取保守表述：按官方当前许可证使用并保留来源声明，官方许可页面为 <https://loinc.org/license/>。目录不声称不确定的具体许可证版本、年份或版权年份；LOINC 不是本目录的最终映射依据。

## 5. 发送与本地校验边界

发送给代理的目录上下文只包含可推荐目录的 `id` 和候选名称，以及用户已确认的名称到目录 ID 映射；不包含健康数值、报告全文、图片或密钥。

模型返回的推荐 ID 在本地再次校验：目录外 ID 被拒绝，`withheld` ID 被拒绝，推荐名称以本地目录显示名为准。`sourceText` 还必须逐字出现在本次发送的识别文本中。所有结果和标签仍是候选，用户确认前不进入正式条目或趋势。

## 6. 后续人工审核

后续审核应逐条核对名称、别名、标本、属性、方法、单位、国家标准数据元和 LOINC 候选的边界，并为每项保留可追溯证据。未完成逐项审核前，不得将目录宣传为已完成医学映射或正式国家编码目录。
